## 2026-06-05 - Rust iterator pattern matching\n**Learning:** When parsing whitespace-delimited logs in Rust, allocating intermediate Vectors `collect::<Vec<&str>>().into_iter()` and doing length checks is a common performance anti-pattern. Direct iterator traversal with tuple pattern matching `if let (Some(a), Some(b), None) = (iter.next(), iter.next(), iter.next())` is strictly better: it guarantees bounded extraction and avoids dynamic heap allocation while preserving readability.\n**Action:** Always prefer direct iterator consumption with bounded pattern matching for fixed-size extractions over Vector allocations across the Rust workspace.
