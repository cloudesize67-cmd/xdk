## 2023-10-25 - Avoid Deep Cloning AST Nodes
**Learning:** In the `xdk-openapi` crate, parsing intermediate OpenAPI components using `serde_yaml::from_value::<T>(val.clone())` or `serde_json::from_value::<T>(val.clone())` causes unnecessary deep clones of the entire Serde Value AST. This is an expensive O(N) operation that allocates significant memory, especially inside iterative loops over schemas or parameters.
**Action:** When a type implements `Deserialize`, prefer calling `T::deserialize(val)` instead, since `Deserialize` is implemented for references to `serde_json::Value` and `serde_yaml::Value`. This allows Serde to borrow from the existing value without cloning. Make sure to import `use serde::Deserialize;` when doing so. Continue to use `from_value(value)` at the end of the parsing process where the full value tree is consumed to allow Serde to move string allocations.
