## 2024-06-25 - [Rust Iterator Allocations]
**Learning:** In Rust, avoid intermediate allocations by iterating directly over iterator sources (like `.split()`) rather than calling `.collect::<Vec<_>>().into_iter()`. Also, use character-based splits (e.g., `.split('\n')`) instead of string-based splits (e.g., `.split("\n")`) for single characters. Furthermore, when transforming and aggregating collections of strings, use `.collect::<String>()` instead of `.collect::<Vec<_>>().join("")` for string concatenation to prevent intermediate vector allocations.
**Action:** When working with iterators and strings in Rust, check for intermediate allocations that can be avoided by directly using `collect::<String>()` or dropping `collect::<Vec<_>>().into_iter()` from iterator chains. Use `char` arguments for single-character string functions to enhance performance.
