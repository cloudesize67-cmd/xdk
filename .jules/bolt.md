## 2024-04-21 - [Optimize String Interpolation and Iteration Allocations]
**Learning:** In Rust, combining iterator adaptors like `.collect::<Vec<_>>().join("")` creates an unnecessary intermediate `Vec` allocation. For simple string building, `.collect::<String>()` is much faster and more idiomatic. Similarly, using `.collect::<Vec<_>>().into_iter()` is a frequent source of performance regressions; iterators can be mapped or consumed directly without materializing them into heap allocations. Also, splitting by single characters (e.g. `\n`) rather than single-character strings (e.g. `"\n"`) executes faster.
**Action:** When performing string interpolations, concatenations, or list evaluations, explicitly check for intermediate `.collect::<Vec<_>>()` calls that immediately iterate or join again. Refactor these patterns to either consume the stream directly or build the required string incrementally. Avoid `.split("char")` when `.split('char')` is possible.
